# Security Admin Module - Developer Quick Reference

## Quick Navigation

### Backend Endpoints Summary
```
Location Management:
  GET    /api/security-admin/locations              ← All locations
  GET    /api/security-admin/locations/:id          ← Single location
  POST   /api/security-admin/locations              ← Create
  PUT    /api/security-admin/locations/:id          ← Update
  DELETE /api/security-admin/locations/:id          ← Archive

QR Operations:
  POST   /api/security-admin/qr/location/:id/generate      ← Generate QR
  GET    /api/security-admin/qr/location/:id               ← Get latest QR
  POST   /api/security-admin/qr/location/:id/download      ← Track download
  GET    /api/security-admin/qr/download-history           ← Download history
  GET    /api/security-admin/qr/generation-history         ← Generation history
  GET    /api/security-admin/statistics/qr                 ← Statistics
```

### Frontend Screens & Components
```
Main Components:
  - SecurityAdminScreen.js      ← Main admin interface
  - SecurityAdminTabNavigator   ← Navigation setup
  - QRPreviewModal              ← QR display component
  - LocationCard                ← Location display component

Services:
  - securityAdminAPI (api.js)   ← All API calls
```

## Common Tasks

### Add New Location Type
1. Update `backend/prisma/schema.prisma`:
   ```prisma
   enum LocationType {
     // ... existing types
     NEW_TYPE
   }
   ```
2. Run migration: `npx prisma migrate dev --name add_new_location_type`
3. Update seed script if needed: `backend/scripts/seed_locations.js`

## Database Query Examples

### Get All Locations with Counts
```javascript
const locations = await prisma.location.findMany({
  include: {
    _count: {
      select: {
        qrGenerationHistory: true,
        qrDownloadHistory: true,
      }
    }
  },
  orderBy: { createdAt: 'desc' }
});
```

### Get Location with Last 10 Generations
```javascript
const location = await prisma.location.findUnique({
  where: { id: locationId },
  include: {
    qrGenerationHistory: {
      orderBy: { generatedAt: 'desc' },
      take: 10,
      include: {
        generatedBy: {
          select: { id: true, name: true, email: true }
        }
      }
    }
  }
});
```

### Get Top 10 Downloaded Locations
```javascript
const topDownloaded = await prisma.location.findMany({
  orderBy: { qrDownloadCount: 'desc' },
  take: 10,
  select: {
    id: true,
    name: true,
    type: true,
    qrDownloadCount: true,
  }
});
```

### Get Download History for User

## Performance Tips

```javascript

  () => locations.filter(loc => loc.name.includes(searchQuery)),

  data={filteredLocations}
  renderItem={({ item }) => <LocationCard {...item} />}
  keyExtractor={item => item.id}
```

### Common Issues & Fixes

| Issue | Fix |
|-------|-----|
| "Authentication required" | Check JWT token in headers |
| "Forbidden access" | Verify user role is "admin" |
| "Location not found" | Check location ID exists in database |
| "QR download failed" | Check file permissions (Android 11+) |
| "Migration failed" | Check PostgreSQL is running, DATABASE_URL is set |
| "Screen not showing" | Verify SecurityAdminTabNavigator is imported in App.js |
| "API timeout" | Check backend server is running, increase timeout |

## Code Style Guidelines

### Backend Route Handlers
```javascript
// Pattern: middleware → validation → operation → response
router.post('/endpoint', authenticate, async (req, res) => {
  try {
    // 1. Validate input
    if (!required_field) {
      return res.status(400).json({ code: 'INVALID', message: '...' });
    }

    // 2. Check permissions
    if (req.user.role !== 'admin') {
      return res.status(403).json({ code: 'FORBIDDEN', message: '...' });
    }

    // 3. Perform operation
    const result = await prisma.model.operation();

    // 4. Return success
    res.status(200).json({ success: true, data: { result } });
  } catch (error) {
    res.status(500).json({ code: 'ERROR', message: error.message });
  }
});
```

### Frontend Component Hooks
```javascript
// Pattern: state → effects → handlers → render
const SecurityAdminScreen = () => {

  const [locations, setLocations] = useState([]);
  
  // Effects
  useEffect(() => { loadData(); }, []);
  
  // Handlers

  // Render
  return (
    <SafeAreaView>
      <View>{/* ... */}</View>
    </SafeAreaView>
  );
};
```

## Extension Points

### Add New Location Type
1. Update LocationType enum in schema.prisma
2. Create migration
3. Update seed script
4. Frontend might need new icon/color mapping

### Add Location Properties
1. Add field to Location model in schema.prisma
2. Create migration
3. Update API routes to include/validate new field
4. Update SecurityAdminScreen to display/edit new field

### Add New QR Format
1. Update qrFormat field validation in API
2. Modify QRPreviewModal to handle new format
3. Update file extension logic in download handler

### Add Geolocation Features
1. Get latitude/longitude from device GPS
2. Compare with location coordinates
3. Calculate distance/proximity
4. Add geofencing logic to arrival detection
