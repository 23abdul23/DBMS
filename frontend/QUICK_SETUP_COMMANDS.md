# Frontend Quick Setup Commands

## Fast Start

```bash
cd frontend
npm install
npm start
```

## Native Run Targets

```bash
cd frontend
npm run android
npm run ios
npm run web
```

## Expo Notes

For push-notification testing, use a development build or native run target instead of Expo Go.

```bash
cd frontend
npx expo run:android
# or
npx expo run:ios
```
